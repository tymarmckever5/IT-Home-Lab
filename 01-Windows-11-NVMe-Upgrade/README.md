# Windows 11 NVMe SSD Upgrade

## Overview

Upgraded my desktop computer by installing an NVMe SSD and performing a clean installation of Windows 11. This project gave me hands-on experience with computer hardware, storage installation, Windows deployment, BIOS/UEFI, boot devices, drivers, and troubleshooting.

## Tasks Completed

- Installed an NVMe SSD into the desktop motherboard
- Verified the new SSD was recognized by the computer
- Used Windows 11 installation media to perform a clean installation
- Installed Windows 11 onto the new NVMe SSD
- Completed the initial Windows 11 setup
- Installed Windows updates
- Installed and verified required system drivers
- Confirmed the computer successfully boots Windows 11 from the NVMe SSD

## Troubleshooting

### Windows Setup Kept Looping Back to the Installer

**Problem:**  
After Windows 11 began installing and the computer restarted, the system booted from the Windows installation USB again instead of continuing the installation from the new NVMe SSD. This caused the Windows Setup screen to appear again and made it seem like the installation had restarted.

**Solution:**  
After the initial installation stage completed and the computer restarted, I removed the Windows installation USB. This allowed the computer to boot from the newly installed NVMe SSD instead of loading the installer again. Windows then continued the installation normally and reached the Windows 11 setup screen.

- How to troubleshoot an installation loop

Successfully upgraded the desktop with NVMe storage and completed a clean Windows 11 installation. The system now boots successfully from the NVMe SSD with Windows updates and required drivers installed.
